# My Personal Portfolio

**Live Website:** [View My Portfolio](https://ekitoepaul.github.io/portfolio/)

This is a four-page personal portfolio website built using HTML and published with GitHub Pages.

## Live Pages

- [Home](https://ekitoepaul.github.io/portfolio/index.html)
- [About](https://ekitoepaul.github.io/portfolio/about.html)
- [Projects](https://ekitoepaul.github.io/portfolio/projects.html)
- [Contact](https://ekitoepaul.github.io/portfolio/contact.html)

## About the Website

The website presents my academic background, research interests, planned projects,
and contact information. It uses semantic HTML elements, including `header`, `nav`,
`main`, and `footer`, to create a clear and accessible page structure.

## Features

- Four linked pages: Home, About, Projects, and Contact
- A consistent navigation menu on every page
- A unique meta description for every page
- Images stored in the `images/` folder with meaningful alt text
- A project summary table using `caption`, `thead`, `tbody`, and `th scope`
- A contact form with connected labels and required fields
- Email, telephone, social media, and external links

## Technologies Used

- HTML5
- Semantic HTML
- Markdown for documentation
- GitHub Pages for hosting

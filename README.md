## About the Website

The website presents my academic background, research interests, planned projects,
and contact information. It uses semantic HTML elements, including `header`, `nav`,
`main`, and `footer`, to create a clear and accessible page structure.

The site follows a mobile-first responsive design approach. The base layout is
designed for small screens, beginning at a 360px viewport, and additional layout
adjustments are applied using `min-width` media queries as the screen becomes wider.

## Responsive Design

The website was designed and tested using a mobile-first workflow:

1. The device toolbar was set to a 360px-wide viewport.
2. Each page was checked at 360px for readability, spacing, navigation, and absence of horizontal scrolling.
3. The viewport was gradually widened to test tablet and desktop layouts.
4. CSS media queries using `min-width` were added to improve the layout at larger screen sizes.
